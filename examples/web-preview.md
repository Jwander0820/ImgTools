# 靜態版範例

可直接開啟 [線上版](https://imgtools.jwander.net/)。需要預覽本機修改時，從專案根目錄執行：

```powershell
cd web
npm.cmd ci --ignore-scripts
npm.cmd start
```

開啟 `http://127.0.0.1:5859`，選擇「台詞疊圖」，選取兩張同尺寸的 PNG／JPEG／WebP。設定字幕帶起點 88%、每句間距 85 px（如果字幕帶不足 85 px，先降低間距），確認預覽，再按「產生 PNG」及下載連結。

「直向疊圖」接受不同高度但同寬的圖片；「文字浮水印」可選多張並逐張下載；「PDF 轉 PNG」選檔後指定頁碼和 DPI，再產生預覽與下載。

可先加入一張圖片，再把下一張從檔案總管拖入頁面。追加圖片與選檔共用限制；切換工具或按清除可重新開始。台詞預覽上方可用滑桿調起點與間距。浮水印預覽上拖曳十字箭頭移動、斜箭頭縮放、環形箭頭旋轉；手機也可觸控操作，或用旁邊的大小與角度滑桿。聚焦控制點後可用方向鍵微調，Shift 加大步幅。平鋪模式用滑桿調整整體字級及角度。

這個流程只在瀏覽器讀取選取檔案，不需要啟動 `ImgTools.cmd`。輸入檔不修改；成果以瀏覽器下載保存。

若要比較本機工作台，依 README 啟動 `ImgTools.cmd` 並開啟 `http://127.0.0.1:5858`。兩版共用主圖示、對應功能圖示及配色；本機頁首顯示 `LOCAL`，靜態版顯示 `WEB`。建置靜態版時需保留專案中的 `imgtools/ui/static/shared/`，發布內容仍只有 `web/dist/`。

若要本機模擬 Cloudflare Pages，使用 `npm.cmd run cf:dev` 並開啟 `http://127.0.0.1:5860`；這不會發布。自動部署先依 [部署文件](../docs/CLOUDFLARE_PAGES.md) 在 Pages 連接 GitHub；之後推送 `main` 即觸發正式建置。可先在本機執行 `npm.cmd run cf:build`，確認模型測試與建置通過。
