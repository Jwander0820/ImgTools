# 本機工作桌迭代

2026-09-20 驗證紀錄。

## 本次調整

- 常用工具改為緊湊橫列，工具庫置於側欄；窄視窗可展開工具庫。
- 主要工作區使用完整可用寬度，操作按鈕固定於底部，進階設定與工作 JSON 收合。
- 改名預設顯示「預覽改名」，結果提供原名、目標名與衝突對照；勾選套用後才顯示實際改名操作。
- TIF 中繼資料提供可搜尋表格；各工具的圖片輸出提供預覽、複製路徑及開啟檔案／資料夾。
- 任務依序執行，切換工具或重新整理仍可查看狀態；支援取消、耗時、處理步驟及最近結果。
- 連線失敗時保留原請求以便去重重試；服務重啟或結果紀錄過期時，阻止不確定的重複執行。
- 前端分成表單、編輯器、結果與任務模組；啟動器優先使用專案 `.venv`。

瀏覽器操作使用 `data/review-v2/` 的測試資料及獨立 `IMGTOOLS_STATE_DIR`，未修改使用者原有偏好或輸入資料。

## 使用限制

- 取消在安全處理節點生效；原生影像編碼或檔案寫入須等待當前步驟結束。已完成輸出保留，未完成的影片轉換不發布。
- 改名開始後須等待完成，排隊中的改名仍可取消。
- 完整結果保留於服務記憶體，最多 50 個已結束任務；重啟後可查閱磁碟上的 manifest，但不會復原任務佇列。
- 輸出預覽為縮圖；GIF 與多頁 TIF 顯示第一幀／頁。
